## About Me

I'm a Full-Stack Developer focused on building intelligent web applications that solve practical problems. I work with technologies such as React, Laravel, PHP, and Python, with an interest in application architecture, backend development, database design, and creating useful user experiences.

I'm expanding my skills in workflow automation with **n8n**, data scraping, and prompt design. I enjoy exploring how websites, APIs, and automated workflows can work together to collect, organize, and process information more efficiently.

My approach combines thoughtful software architecture with practical development: understanding the problem, choosing suitable technologies, structuring the application clearly, and building solutions that can evolve as requirements change.

### Current Focus

- Building intelligent and practical web applications
- Designing maintainable frontend and backend architectures
- Automating repetitive tasks and connecting services with n8n
- Collecting and processing web data through scraping workflows
- Improving prompt design and the use of AI development tools
- Building reliable applications with clear data flows and API integrations
